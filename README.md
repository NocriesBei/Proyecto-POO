# Sistema POS - Taquería Peñascal
Aplicación de escritorio para la gestión de punto de venta (POS), cobros e impresión de tickets.

## Tecnologías Utilizadas
* Lenguaje: Java (Swing)
* Base de Datos: MySQL
* Arquitectura: MVC
